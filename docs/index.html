重点功能

外壳不硬编码任何功能界面：键盘、单位换算、图形、历史都由插件贡献。禁用某个插件，它的界面就立刻消失。

无限画布

没有页面边界：计算过程、笔迹、文字、图形、AI 回答都可以摆在画布上的任意位置，无限平移缩放，需要多大就有多大。

插件驱动

内置 8 个插件，贡献菜单、快捷键、工具与面板。插件可以读画布、访问数据库、修改画布，都要先拿到你的授权。

iPadOS 18 四模式

画布上只有一个计算器，内部切换基础 / 科学 / 换算 / 数学笔记。基础与科学共用同一份表达式，科学模式有 MC/M+/M−/MR 内存键；换算把结果区变成两行单位并对调；汇率默认离线手动、失败即「汇率不可用」，绝不用猜测值冒充实时汇率。

单位换算

14 个类别、376 个单位；支持中文单位名，直接写「3米转厘米」就能算，双向实时换算。

数学笔记

逐行实时求值，变量跨行共享；写 y=f(x) 就直接画出函数图，可缩放平移、读取坐标、把结果回填到画布。

手写转文字

完全离线的笔迹识别器，本地优先；可选加载你自备的 ONNX 模型。清晰就直接识别，不清晰就标注，概率相近就停下来让你选。

圈画问 AI

用套索圈住画布上的任意内容，先预览将要发送的确切内容（文本原文、图片缩略图、字节数、目标服务与模型），确认后才发出去。

计算历史

历史持久化到本地数据库，可搜索、可一键回插画布，接着上次的推导继续算。

隐私与授权

这是本项目的核心设计，不是附加项。插件默认什么都做不了，能做什么由你逐项决定，而且随时可以收回。

能力制授权，逐次校验

插件必须在清单里声明所需能力（画布读写、数据库、网络、AI、摄像头等），授权在每一次 API 调用时重新校验，而不是只在加载时检查一次。未授权直接抛 PermissionDeniedException，你可以在插件管理器里随时撤销任何一项。

云上传默认关闭

全局开关默认关闭，此时任何插件都无法把内容送出这台设备。开启后依然逐次确认：对话框里列出发起插件、用途、目标服务、模型、字符数与字节数，并逐条展示文本原文。你可以选择「仅发送文字」，图片一律剔除。禁止整画布外传，超过大小上限在询问之前就直接拒绝。

本地审计，密钥不落明文

所有上传（无论允许还是拒绝）都写入本地上传审计表，你可以在「插件 → 上传审计」里查看。云供应商的 API key 用 DPAPI（Windows）或 AES-256-GCM 加密，保护失败时拒绝落盘并显式标记。没有遥测：这个页面除了读取版本号，不会向任何地方发送数据。

本地优先： 手写识别与问答都先走本机路径，云端是可选增强而不是默认依赖；本地端点可用时不会触发任何上传确认。
